# find-similar-items-on-massive-datasets

[![Open Notebook In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/fil-noct/find-similar-items-on-massive-datasets/blob/main/notebook.ipynb)

The main objective of this project is to implement a scalable, data-mining-oriented, comparison algorithm to detect similar text based items.
The core computation consists of finding the candidate pairs in a document collection and verifying the pair true Jaccard similarity, that, using parameters optimization techniques, is within a certain threshold bound specified by the user.
